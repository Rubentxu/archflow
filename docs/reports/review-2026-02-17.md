# EPIC-ECS-009: WASM Migration

## Criterios de Aceptación

| Criterio | Estado | Evidencia |
|-----------|--------|-----------|
| set_shape() deprecado | ❌ | NO deprecated - solo funciona |
| Nueva API shape() | ✅ | JsEntityBuilder.shape() |
| Query API en WASM | ✅ | 4 nuevos métodos |
| Eliminar arrays legacy | ⏳ Pendiente | No implementado |

## Review Detallado

### ✅ HU-ECS-009-01: Migrar set_shape a ECS
- JsEntityBuilder con `shape()`, `color()`, `position()`, `size()`, `layer()`, `visible()`
- ShapeTypes constants disponibles
- **⚠️ Gap**: `set_shape()` en bridge_wasm.rs NO está deprecated

### ✅ HU-ECS-009-02: Query API en WASM
- `query_shape_components()` - entidades con ShapeComponent
- `query_color_components()` - entidades con ColorComponent
- `query_visible_entities()` - entidades visibles
- `query_by_shape_type(shape_type)` - filtrar por tipo
- `get_ecs_component_count()` - diagnósticos
- `get_ecs_entity_count()` - diagnósticos
- ECS World añadido a ArchFlowEngine

### ⚠️ HU-ECS-009-03: Eliminar arrays legacy
- **Estado**: Pendiente
- EntityStore sigue usando arrays SoA
- ecs_world coexiste pero no está sincronizado
- Requiere plan de migración gradual

## Deuda Técnica

| Item | Severity | Descripción | Solución |
|------|----------|-------------|----------|
| set_shape no deprecated | Alta | API legacy sigue sin warning | Añadir `#[deprecated]` attribute |
| EntityStore arrays | Media | Legacy arrays coexisten | Migración gradual |
| ECS-World sync | Media | No sincronizado con EntityStore | Sincronización en tick() |

# Análisis de Similitudes y DRY

## ✅ Código DRY
- Transform reutilizado de physics_components
- Component trait usado consistentemente
- No hay duplicación de lógica

## ⚠️ Preocupaciones de Arquitectura

### Coexistencia ECS + EntityStore
El proyecto tiene dos sistemas paralelos:
1. **EntityStore** (legacy): arrays SoA, usado activamente
2. **ecs::World**: ECS moderno, no sincronizado

Esta arquitectura es válida durante transición pero requiere documentación clara del roadmap de migración.
